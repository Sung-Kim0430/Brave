## 第二轮修复（安全和功能）

### 安全修复

#### 1. URL 验证绕过漏洞 🔴 紧急
- **文件**: `core/App.php:264-270`
- **问题**: 协议相对URL (`//example.com`) 绕过危险scheme检查
- **修复**: 对 `//` 后的内容也进行scheme检查
- **影响**: 防止 `//javascript:alert(1)` 类型的XSS攻击

#### 2. ReDoS 攻击风险 🔴 紧急
- **文件**: `core/App.php:140, 185`
- **问题**: Love List shortcode 正则可能导致灾难性回溯
- **修复**: 
  - 限制总内容长度 100KB → 50KB
  - 限制项目数量 200个
  - 早期返回避免无效处理
- **影响**: 防止CPU 100%占用和DoS攻击

#### 3. DOMDocument DoS 攻击 🔴 高
- **文件**: `core/App.php:515`
- **问题**: 深度嵌套HTML导致内存耗尽
- **修复**: 限制HTML内容为50KB，超出截断
- **影响**: 防止恶意评论使PHP进程崩溃

#### 4. Helper 类依赖说明
- **文件**: `core/App.php:9`
- **修复**: 添加注释说明依赖Typecho的Helper类

### 功能性修复

#### 5. PJAX 初始化问题 🔴 高
- **文件**: `base/main.js:472-503`, `base/footer.php:183`
- **问题**: pjax导航后只恢复计时器，其他功能全部失效
- **修复**: 创建 `reinitAfterPjax()` 重新绑定所有功能
- **影响**: 确保主题切换、返回按钮、TOC、代码复制、图片预览正常

#### 6. JavaScript falsy 值陷阱
- **文件**: `base/main.js:328`
- **问题**: `!text && text !== ''` 无法处理数字0和false
- **修复**: 改为 `text == null || text === ''`
- **影响**: 用户可以复制包含"0"的代码

#### 7. 全局监听器重复绑定
- **文件**: `base/main.js:437-442`
- **问题**: lightbox的Escape键每次都绑定
- **修复**: 使用全局标志防止重复绑定
- **影响**: 防止性能下降和多次触发

#### 8. IntersectionObserver 内存泄漏
- **文件**: `base/main.js:196-207, 315`
- **问题**: disconnect()后旧标题节点未unobserve
- **修复**: 记录观察的节点，清理前逐个unobserve
- **影响**: 防止多次pjax导航后内存累积

### 代码质量改进

#### 9. optionFlag 类型转换
- **文件**: `core/App.php:55`
- **修复**: 添加注释说明回退逻辑

#### 10. innerText 兼容性
- **文件**: `base/main.js:357`
- **修复**: 替换为 textContent 提升性能和兼容性

#### 11. slugify Unicode 支持
- **文件**: `base/main.js:153-168`
- **修复**: 改进中文标题处理，明确回退策略

#### 12. 事件按钮检查
- **文件**: `base/main.js:133`
- **修复**: 使用 `!= null` 正确检查button属性
